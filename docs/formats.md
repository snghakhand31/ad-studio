# Ad format catalog (pick from the reference, or propose one)

Every format = beats + layouts. Mix freely; these are starting points, not limits.

| Format | Beats | Build with |
|---|---|---|
| **News debate** | shock claim on TV → promise + B-roll → demo → CTA | `news` preset + `full` + `endcard` |
| **UGC testimonial** | face-to-camera hook ("Maine socha bhi nahi tha…") → problem → app moment → result → CTA | `custom`: 9:16 Veo talking head full-bleed, `outline` captions, html stickers |
| **Problem → solution** | relatable pain (B-roll) → "phir maine ye try kiya" → demo → payoff | `custom` B-roll + text hook, `full` demo |
| **Split reaction** | top: speaker/claim, bottom: reaction or proof | `custom` two video layers top/bottom |
| **Text-on-screen / meme** | big text punchlines over B-roll, fast cuts 1–2s | `custom` with `html` big text, `box` dim, `bgm` |
| **Founder / expert talk** | authority intro lower-third → insight → offer | `custom` talking head + html lower-third |
| **Demo walkthrough** | "3 steps mein…" numbered steps over recordings | `full` with recordings + html step badges |
| **Before / after** | split or sequential comparison | `custom` split + labels |
| **Festival / moment** | festival hook → emotion B-roll → product → greeting CTA | any of the above + festive html graphics |

Veo aspect: 16:9 for panels/split bands, **9:16 for full-bleed** talking heads and B-roll (set Flow video default to 9:16 for those).
Hooks: first 1.5s must show the hook visually AND textually; captions always on (most feeds autoplay muted).
